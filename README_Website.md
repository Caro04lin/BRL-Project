# Website

The developed web site enables users to operate the differents models to predict their motions while performing painting tasks. 

<img width="1186" height="670" alt="Website" src="Web site/Prediction_interface.png" />

Clicking on the i information displays the prequerisites. It details the instructions about the IMU Wi-Fi configuration, the prerequisites for connecting the IMUs and the wireless camera to the laptop, and the recommended use of a Wi-Fi adapter.

The web site outputs the number of hands used, the action performed, the tool held in hands and the prediction time.

Choose one deep learning model between:
- LSTM
- GRU
- CNN-GRU
- TCN
